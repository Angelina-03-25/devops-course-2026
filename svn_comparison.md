# Git vs SVN

1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
   В Git ветка — просто указатель на коммит, создаётся мгновенно.
   В SVN ветка — копирование директории, медленно и затратно.

2. Можно ли в SVN сделать коммит без интернета? Почему?
   Нет. SVN централизованная: коммит идёт напрямую на сервер.
   Без сети коммит невозможен.

3. В каких сценариях SVN до сих пор предпочтительнее Git?
   В legacy-проектах (госсектор, банки), где инфраструктура SVN
   уже настроена и миграция нецелесообразна.
